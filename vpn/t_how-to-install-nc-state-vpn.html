Install the NC State VPN

Downloading and installing Cisco Secure Client on supported devices to access the NC State VPN.

Verify whether you are installing the VPN client on a personal or university-owned device:

  • Personal devices (students and personal computers): You can download and install Cisco Secure Client directly using the steps below.
  • University-managed devices (faculty and staff): Cisco Secure Client is pre-installed on many university-issued computers. If you use a university-provided device and need help installing the client, contact your local department IT support team.

NC State supports Cisco Secure Client on Windows 10 and 11, Windows on ARM processors, macOS 13 or newer, Linux (via OpenConnect), ChromeOS, Android, and iOS (iPhone or iPad).

  1. Open a web browser and go to the NC State VPN installation portal at https://go.ncsu.edu/install-vpn.
  2. Sign in with your NC State Unity ID and password if prompted.
  3. Select your device's operating system (such as Windows 10 and 11, macOS 13 or newer, Android, or iOS) to view the platform-specific installer.
  4. Download the Cisco Secure Client installer package for your operating system and follow the on-screen installation prompts to complete setup.

    On macOS, open the downloaded disk image, double-click Cisco Secure Client.pkg, accept the license agreement, and keep AnyConnect VPN selected during installation.

  5. Open Cisco Secure Client from the Start Menu (Windows) or Finder (macOS) to verify that the application launches properly.

Cisco Secure Client is installed on your device and ready to connect to the NC State VPN.
